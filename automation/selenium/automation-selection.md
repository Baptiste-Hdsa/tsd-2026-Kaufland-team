# Automation Selection - Lab 4

## Selected test cases from Lab 3
| TC ID | Title | Automate? | Reason |
|---|---|---|---|
| TC-001 | User Registration and Valid Login Flow | Yes | Stable, critical user journey, highly repetitive |
| TC-004 | New Message Creation and Delivery Check | Yes | Core functionality, stable layout and reliable workflow |
| TC-009 | Visual Layout / Theme Toggle Aesthetics | No | Requires subjective human judgment on rendering and colors |

## Explanation
* **TC-001 & TC-004** are stable, repeatable, and run with predictable input data, making them ideal candidates for Selenium IDE automation.
* **TC-009** involves visual aspects and user comfort that cannot be accurately verified by simple text/element assertions.
