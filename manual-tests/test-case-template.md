# Test Case Template

| Field | Description |
|---|---|
| **Test Case ID** | Unique identifier (e.g., TC-001) |
| **Title** | Short descriptive name of the test |
| **Feature** | The functionality being tested |
| **Priority** | High / Medium / Low |
| **Type** | Functional / UI / API / Negative |
| **Preconditions** | What must be true before execution |
| **Test Data** | Inputs and user accounts used |
| **Steps** | Numbered step-by-step actions to perform |
| **Expected Result** | Observable expected behavior |
| **Actual Result** | Filled during execution |
| **Status** | Not Run / Passed / Failed |
